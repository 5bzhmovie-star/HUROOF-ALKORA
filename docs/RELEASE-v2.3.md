# حروف الكورة — Windows v2.3.0

عند كشف حل التشكيلة تظهر صورة اللاعب الفعلية بدل انعكاس العلم. أُزيل الاعتماد على قلب ثلاثي الأبعاد كان يتعطل بسبب مرشح الظل، مع حركة كشف قصيرة واحترام تقليل الحركة. إذا كانت صورة اللاعب ناقصة يظهر تنبيه واضح بدل عرض العلم كأنه صورة اللاعب.

إضافة عناصر المكتبة تبدأ بالاسم والتصنيف فقط؛ الصورة والاسم الإنجليزي والمصدر وبقية التفاصيل اختيارية. يمكن إضافة لاعب أو نادٍ أو منتخب أو مدرب أو علم أو دولة أو بطولة أو ملعب أو مباراة أو موسم، ثم تعديل الاسم والصورة والبيانات من بطاقة العنصر. تبقى العلاقات التاريخية والحقول غير المعدلة محفوظة.

رفع الصور متاح داخل حقول الأسئلة والمكتبة مباشرة، مع السحب والإفلات ولصق صورة من الحافظة. تُجهز الصورة محليًا وتُحفظ في ملفات التطبيق وكتالوج الصور، وتعود عند إعادة فتح التطبيق وعند اختيار اللاعب للتعبئة التلقائية. لا يتطلب رفع صورة شخصية رابط مصدر أو ترخيصًا مكتوبًا. يُمنع حفظ السؤال أو تغيير المحتوى أثناء تجهيز الصورة لتفادي حفظ صورة قديمة. الصور المرتبطة بالأسئلة المنشورة لا تتغير بأثر رجعي؛ لجلب تعديل مكتبة جديد في سؤال سابق أعد اختيار العنصر واحفظ السؤال.

تشمل الحزمة 271 علمًا من flag-icons 7.5.0، و211 منتخبًا عضوًا في FIFA بأسمائها العربية والإنجليزية ورموزها. تندمج رموز البحث الجديدة مع الأعلام القديمة عند التحديث، مع الحفاظ على تعديلات المستخدم. توسعة المنتخبات تضيف الهوية والعلم؛ التعبئة الكاملة للتشكيلة تعتمد على مباراة مسجلة أو تشكيلة حفظها المستخدم، ولا تنشئ أسماء لاعبين أو خطة مفترضة من اسم الفريق وحده.

التحقق: 65 اختبار خادم ناجح، وفحص TypeScript لواجهة نسخة سطح المكتب، وبناء واجهة الإنتاج. اختبار Chromium فعلي للإضافة والتعديل ورفع الصور وبقاء البيانات بعد إعادة التحميل، والتعبئة التلقائية، ونشر سؤال شخصي بلا مصدر، ومنع الحفظ أثناء رفع مؤجل، وقياس واجهة 390 بكسل دون تجاوز أفقي أو أخطاء JavaScript. اختبار بكسل للعلم/الصورة أكد ظهور الصورة بعد الكشف. نجحت اختبارات C# لمنطق التحميل والمهلة والفشل وإعادة المحاولة، وتجميع Windows x64 ذاتي الاحتواء. لم تُشغّل نافذة WinForms الأصلية على Windows داخل بيئة Linux.

فك ضغط الحزمة كاملة ثم شغّل HuroofAlKora.exe مع إبقاء مجلد game بجانبه. يبدأ بشاشة التحميل الحالية ثم اللعبة بلا إطار. لا يحتاج CMD أو تثبيت Node أو .NET، ويحتاج WebView2 Runtime الموجود عادة على Windows. بيانات اللعبة السابقة في حساب المستخدم تبقى منفصلة عن ملفات الحزمة.
