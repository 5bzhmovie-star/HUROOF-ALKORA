# حروف الكورة — Windows v2.1

أضيفت أربعة أنواع إلى بنك الأسئلة المصورة وإعدادات اللعب:
- مسيرة مدرب: 3–8 محطات وشعارات وسنوات وصورة الحل.
- وش الرابط: أربعة لاعبين وشرح للرابط يظهر عند الحل.
- الدخيل: أربعة لاعبين وتحديد واحد، مع إظهار السبب عند الحل.
- مين الناقص؟: تشكيلة من 11 لاعبًا يُخفى منها اسم وصورة لاعب واحد حتى كشف الإجابة.

الأنواع الثمانية قابلة للتصفية والنسخ والتعديل والحفظ كمسودة والنشر، وتدخل السحب العشوائي حسب الحرف والبطولة وأنواع الغرفة. لا تُرسل إجابة اللاعب الناقص أو مؤشر الدخيل أو شرح الرابط إلى شاشة اللعب قبل الكشف. الترقيات تحافظ على الأسئلة القديمة.

## الأعلام والتشكيلات

حزمة 261 علمًا محليًا (flag-icons 7.5.0، MIT) و48 منتخبًا و48 اسم مدرب من ملفات المشروع. البحث بالأسماء العربية والإنجليزية ورموز البلدان. يُملأ علم الجنسية عند جلب اللاعب، ويمكن اختياره يدويًا. تم إصلاح ملء علم منتخب موجود قديمًا بلا صورة مع الحفاظ على التعديلات اليدوية.

التعبئة تبدأ باختيار الفريق ثم مباراة مؤرخة. توجد أربع تشكيلات تاريخية مرجعية: ريال مدريد وليفربول (نهائي الأبطال 2022-05-28)، والأرجنتين وفرنسا (نهائي كأس العالم 2022-12-18). التشكيلات والمراكز مستندة إلى ملفات UEFA وFIFA المرتبطة داخل السجل. الصور التعريفية المتوفرة تُربط بتطابق الهوية، ولا تُستبدل الأندية التاريخية بالأندية الحالية. الصور والشعارات غير المتوفرة تظهر كعناصر ناقصة قبل النشر؛ لا تتضمن هذه النسخة كل المباريات أو أحدث تشكيلات كل فريق. يمكن حفظ تشكيلة مدخلة يدويًا في سجل الفريق لتعبئتها مجددًا، وتعديل الخطة والمواقع بالسحب أو منزلقات موضع اللاعب.

## التحقق

اختبارات العقود، الخصوصية، النشر، السحب، الغرف، النسخ، وترقية قاعدة v2.0. اختبار واجهة Chromium للبطاقات والملعب وإخفاء لاعب واحد وعرض هاتف 390px دون تجاوز أفقي. فحص TypeScript لإصدار سطح المكتب وبناء React وتجميع EXE ذاتي الاحتواء لـ Windows x64. لم يُنفّذ تشغيل واجهة Windows الأصلية داخل هذه البيئة.

## التشغيل

فك ضغط الحزمة كاملة ثم شغّل HuroofAlKora.exe. يجب إبقاء مجلد game بجانب EXE. يستخدم التطبيق WebView2 الموجود على Windows. البيانات المحلية محفوظة خارج مجلد البرنامج؛ لا تحذف بيانات النسخة السابقة. حزمة الصور وملفات اللعبة مضمّنة للتشغيل دون إنترنت. حقوق صور المصدر السابقة تبقى موضحة داخل المكتبة بانتظار المراجعة.
