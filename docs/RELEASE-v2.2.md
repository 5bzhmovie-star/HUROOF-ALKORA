# حروف الكورة — Windows v2.2.0

تشغيل HuroofAlKora.exe يعرض شاشة تحميل أصلية باسم «حروف الكورة» وشعار Goal نفسه المستخدم في واجهة اللعبة، ثم يفتح الصفحة الرئيسية تلقائيًا. النافذة بلا إطار أو شريط Windows أو شريط Windows Edition، وتبدأ بملء الشاشة. تم استبدال الأيقونات القديمة للشريط والملف وقائمة التطبيقات بالشعار الصحيح، مع تضمين خط Cairo وترخيصه.

شاشة التحميل تنتظر تحميل الصفحة وجاهزية واجهة اللعبة والخطوط، ثم تزيل الغطاء تلقائيًا. تظهر إعادة المحاولة عند الفشل، ولا تفتح استجابة قديمة شاشة جديدة. التحميل القصير له حد عرض 550ms لتفادي الوميض، وحد انتظار عرض الصفحة 30 ثانية. يتوقف تحريك شاشة التحميل عند إخفائها.

خيارات البرنامج داخل زر صغير بشعار اللعبة أسفل اليسار: الإدارة، الشبكة المحلية، الخادم الجماعي، التحديث، التصغير، الإغلاق. F11 يبدل ملء الشاشة، Alt+F4 يغلق التطبيق. في الوضع النافذي يمكن السحب من عنوان قائمة الخيارات. إعدادات الأمان وبيانات المستخدم وملفات المكتبة السابقة محفوظة.

التحقق: تجميع Windows x64 ذاتي الاحتواء؛ اختبار C# فعلي لمنطق انتقال التحميل والفشل والمهلة وإعادة المحاولة؛ تجربة Chromium للنص البرمجي المضمن مع واجهة اللعبة الحقيقية، تشمل تأخير بيانات البداية وتهيئة الخطوط وأوامر القائمة وEscape ورفض إشارات صفحة قديمة وواجهة الكسول وعدم تكرار التحكم داخل iframe؛ فحص TypeScript وبناء الواجهة والاختبارات الـ64. لم يُنفّذ تشغيل نافذة Windows الأصلية في بيئة Linux، ولا تُعد هذه الاختبارات تحققًا بصريًا من WinForms على Windows.

فك ضغط الحزمة كاملة، ثم شغّل HuroofAlKora.exe مع إبقاء مجلد game بجانبه. لا تحتاج CMD أو تثبيت Node أو .NET، ولا صلاحيات مسؤول. يلزم WebView2 Runtime الموجود عادةً على Windows. بيانات اللعبة في حساب المستخدم منفصلة عن مجلد الحزمة.
