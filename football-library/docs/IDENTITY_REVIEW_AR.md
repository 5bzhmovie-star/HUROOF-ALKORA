# مراجعة هوية لاعبي الدوريات الثلاثة

المخرجات الفعلية في `data/identity_review_2026_10_18/`: قاعدة `identity_review.sqlite` وملفات JSON مقسمة مع بصمة وحجم وعدد صفوف كل جزء في `index.json`.

هذه قاعدة أدلة للمراجعة، وليست بديلًا عن `catalog.sqlite` ولا شهادة اكتمال. تحتفظ بسجلات المصادر مستقلة عن الأشخاص النهائيين، ولا تعد سجلات المصدر المختلفة لاعبين مختلفين. لم يتغير سجل كأس العالم أو نادي اللاعب وقت البطولة.

- `observations`: معرف المصدر ومساحته الاسمية، النادي، الاسم المنشور، تاريخ الميلاد، رابط المصدر وبصمة ملف الإدخال.
- `fifa_targets`: هويات لاعبي وثيقة كأس العالم، مع النادي وقت البطولة.
- `candidates`: اقتراحات الربط فقط؛ `merge_approved=0` إلزامي.
- `review_status`: حالات عدم التطابق أو نقص الميلاد أو تضارب الميلاد أو الالتباس.
- `media_candidates`: ربط صورة محلية بسجل المصدر والنادي، بمطابقة عنوان الصورة الأصلي وسياق المعرفين. جميعها غير معتمدة للأسئلة.

المطابقة تستخدم الاسم المنشور الكامل أو اسم العرض المنشور وتاريخ الميلاد الكامل. يُتجاهل اختلاف حالة الأحرف وعلامات الترقيم والتشكيل اللاتيني. لا يُستخدم تشابه الاسم أو اسم العائلة وحده أو اسم القميص لإثبات الهوية. لا يُعامل تساوي رقمين في مصدرين على أنه تطابق هوية. التطابق الوحيد يبقى اقتراحًا حتى مراجعة الأدلة؛ الالتباس لا ينتج دمجًا تلقائيًا.

تحتوي اللقطة 2085 ملاحظة مصدر: 587 من LaLiga، و544 من المصدر السعودي الأساسي، و481 من واجهة الدوري الإنجليزي الأولى، و473 من واجهته الثانية. هذه أعداد ملاحظات وليست عدد أشخاص فريدين. توجد 176 وصلة مقترحة إلى 109 لاعبين مختلفين في قائمة FIFA. توجد 1016 وصلة صورة سياقية للاعبي الإسباني والسعودي؛ لا تعني اعتماد الهوية أو الموسم أو الحقوق، ولا تشمل جميع صور الإنجليزي المجموعة.

يمكن فحصها محليًا بأي قارئ SQLite. مثال لاستخراج المقترحات مع مصدرها:

```sql
SELECT o.namespace,o.source_person_id,o.club_id,c.target_id,c.status,o.payload
FROM observations o JOIN candidates c ON c.source_id=o.id
ORDER BY o.namespace,o.source_person_id;
```

لإعادة البناء دون الكتابة فوق تقدم سابق:

```text
python football-library/scripts/build_identity_review.py football-library NEW_OUTPUT_DIRECTORY
```

لا يحتاج البناء إلى اتصال أو مكتبات Python إضافية. لم تُستورد هذه المقترحات إلى قاعدة اللعبة، ولم تُنشأ كيانات مكررة من السجلات غير المتطابقة. المسار التالي هو مراجعة الوصلات، ثم ربط الهويات الجديدة غير الموجودة في FIFA، ثم استيراد المعتمد فقط عبر مسار اللعبة مع صور النادي والمنتخب كل في سياقه الزمني.
