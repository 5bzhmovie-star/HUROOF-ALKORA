# حروف الكورة Windows Edition v1.2.1
## الإصلاحات
- هوية Windows تعتمد خلفية الموقع الداكنة #10201f وأخضر #c2f17c.
- تتولد أيقونات Windows وقت البناء باستخدام رسم محلي، بدون تحميل صور خارجية.
- تم تحصين تحديثات الجرس وشاشات Mini Games ضد البيانات الجزئية واستقبال الاستجابات الناقصة.
- يحافظ على اللعب المحلي، المحرك الداخلي، صلاحيات المستخدم العادي، ووضع الإنترنت.

## البناء
من GitHub Actions: Windows portable build على فرع development/source-import.
ستجد Artifacts باسم Huroof-AlKora-Windows-x64.
بعد فك ZIP داخله، افتح HuroofAlKora.exe مع الاحتفاظ بمجلد game كاملًا.

## التحقق
نجاح البناء والاختبارات لا يساوي اختبارًا تفاعليًا على جهاز Windows؛ اختبر صفحة المقدم، الجرس، فتح/انتهاء الوقت، والصورة والأيقونة قبل نشر المتجر.
