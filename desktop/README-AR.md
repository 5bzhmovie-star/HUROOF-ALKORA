# حروف الكورة | Windows Edition v1.3.0

## التشغيل

1. فك حزمة Windows بالكامل، ولا تفصل EXE عن مجلد `game`.
2. افتح `HuroofAlKora.exe` بصلاحيات المستخدم العادية.
3. «محلي سريع»: اللعب والخادم على جهازك، دون اتصال خارجي.
4. «شبكة LAN»: يسمح لجوالات وأجهزة شبكتك بالانضمام. قد يطلب جدار حماية Windows السماح للاتصالات الواردة، ولا يتطلب EXE تشغيله كمسؤول. لا تستخدمه على شبكات Wi-Fi العامة.
5. «خادم جماعي»: أدخل عنوان HTTPS لخادم حروف الكورة المستقل الذي تديره؛ لا يتصل التطبيق بموقع ChatGPT Sites. **ملاحظة:** الاستضافة العامة ليست مضمنة في EXE ولا يمكن ادّعاء وجود خادم عالمي جاهز بدون استضافة فعلية.
6. «لوحة الإدارة»: أول مرة يُنشئ البرنامج حساب مالك بكلمة مرور قوية وTOTP عبر نافذة خاصة، وليس عبر CMD. بعدها تسجل الدخول من صفحة /admin. حماية حساب المالك خاصة بكل خادم/قاعدة بيانات.

## العلامة التجارية

شعار أيقونة البرنامج مطابق لمسار SVG الأصلي لرمز Lucide Goal (ثلاثة paths وبدون كرة إضافية)، لون `#c2f17c` ومحتوى `#163329` مع الخلفية الدوّارة -8°.

## الأمان

- صلاحيات المستخدم العادي فقط؛ لا واجهة native privileged bridge للويب.
- خادم loopback افتراضيًا. LAN خيار صريح، ومنع API إدارة البرنامج عن العملاء القادمين من LAN HTTP.
- تشغيل first-run bootstrap عبر stdin/stdout خاصة بعملية Node فرعية، وليس endpoint HTTP.
- لا أسرار صلبة أو حسابات مدير افتراضية. كلمة المرور مخزنة بنظام scrypt والتحقق TOTP.
- لا ينبغي نشر خادم Node الخام عبر الإنترنت بلا HTTPS + جدار ناري + ضبط أمان.
- ملفات وأسئلة وبيانات المستخدم في `%LOCALAPPDATA%\HuroofAlKora\data`؛ حافظ على نسخك الاحتياطية.
- لعدم السماح بصلاحيات مرتفعة تلقائيًا، قد تتطلب إعدادات جدار حماية Windows إجراءً يدويًا من المستخدم إذا كانت الشبكة تمنع استقبال الاتصالات.

## الاختبارات

GitHub Actions يبني Windows، يجري اختبارات الخادم، ويخرج ZIP محمول. نجاح البناء لا يثبت أداء الإنترنت البعيد أو جودة اتصال جهاز على شبكة أخرى. اختبر فعليًا مسار LAN والجرس ولوحة الإدارة قبل إعلان الإصدار النهائي أو النشر في Microsoft Store.
