# حروف الكورة | HUROOF ALKORA

لعبة أسئلة وتحديات كروية جماعية، ونسختها الرسمية للمتصفح وWindows.

> **حالة المستودع:** جارٍ تأسيس مستودع المصدر. لا تعتبر تنزيلات GitHub جاهزة قبل نجاح بناء Windows واختبارات اللعب الفعلية. 
> المصدر المعتمد للتطوير هو حزمة `Huroof-AlKora-Windows-v1.2.0-PRO-Source.zip` المحفوظة من إصدار اللعبة السابق. لا تُنشَر ملفات المستخدمين أو قواعد بيانات الإنتاج أو الأسرار.

## أهداف الإصدار

- تطبيق Windows باسم وهوية وشعار وشاشة بدء عربية، بدون صلاحيات مسؤول.
- واجهة ومحرك اللعبة يعملان محليًا عبر WebView2 وNode.js، لا مجرد فتح موقع خارجي.
- تحديثات الغرف المباشرة، عداد منفصل وشبكة حروف محسّنة.
- لعب أونلاين عبر خادم موثوق مع تحقق نتائج وضوابط وصول مستقلة عن العميل.
- بناء `EXE` محمول وتغليف `MSIX` اختياري عندما تتوفر هوية Microsoft Partner Center.

## بنية المصدر المستهدفة

```text
website/                # لعبة المتصفح ومحرك Node/SQLite والاختبارات
desktop/src/HuroofAlKora # تطبيق Windows باستخدام WinForms + WebView2
desktop/scripts/        # بناء EXE وMSIX وإعداد التوزيع
.github/workflows/      # CI وفحوص الأمان والبناء على Windows
docs/                   # خطة الإصدار والهندسة والأمان
```

## حدود الأمان

لا توجد أسرار خادم داخل `EXE`، ولا يُطلب تشغيله كمسؤول. تطبيق المستخدم لا يملك صلاحية إصدار نتائج عامة موثوقة أو إدارة غرف الآخرين. الأمان الحقيقي يعتمد على التحقق الخادمي، عزل العمليات، عدم استخدام الصلاحيات المرتفعة، وتحديث المكونات. تعطيل أدوات المطور ليس آلية منع غش.

## التحميل والبناء

بعد استيراد المصدر كاملًا، يُنشأ إصدار Windows في GitHub Actions عن طريق `desktop/scripts/Build-Release.ps1`. تشغيل `EXE` النهائي مشروط بمرور الاختبارات، ووجود `website/seed/questions.json` وبقية الملفات المطلوبة. لا تنشر ملف EXE ناقصًا أو حزمة MSIX غير موقعة على أنها نسخة نهائية.

التطوير يُجرى على فروع منفصلة مع Pull Requests، بينما يبقى `main` فرعًا مستقرًا.
