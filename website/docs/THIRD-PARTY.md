# الاعتمادات

- React وReact DOM ومكتبات الواجهة: تراخيصها الأصلية محفوظة في `licenses/dependencies/`، وإصداراتها مثبتة في `pnpm-lock.yaml`.
- shadcn/ui وRadix UI وLucide: واجهات وأيقونات بترخيصها الأصلي، دون شعارات أندية أو بطولات محمية ضمن التصميم.
- Noto Sans Arabic: SIL Open Font License 1.1، نسخة الرخصة وحقوق الخط في `public/fonts/OFL.txt`. جرى تحويل الملفات إلى WOFF للويب.
- مولد QR المحلي: Kazuhiko Arase / qrcode-terminal، رخصة MIT في `server/vendor/qr/LICENSE`.
- بيانات OpenFootball/FootballCSV: CC0/ملكية عامة وفق مشاريعها؛ روابط الوقائع في كل سؤال وفي `docs/QUESTIONS.md`. مقتطفات الجداول التاريخية من ويكيبيديا تخضع لشروط مصادرها، وصياغة الأسئلة عربية خاصة بالمشروع.
- صورة المشاركة: أصل بصري مولد للمشروع. الأيقونة هندسية محلية؛ لا يعتمد اللعب على خدمة صور خارجية.
