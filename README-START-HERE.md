# حروف الكورة — نسخة Windows الاحترافية v1.2.0

**اقرأ هذا أولًا**

هذه حزمة المصدر الكاملة والمحدّثة للعبة حروف الكورة، وليست ZIP تطبيق جاهز للنقر مباشرة؛ لا يمكن إخراج Windows EXE الحقيقي هنا لأن أدوات بناء Windows غير موجودة. المشروع يتضمن واجهة بدْء أصلية، أيقونة، وضع محلي سريع ووضع أونلاين، ومشروع بناء حزمة للمتجر.

لتصنيع الحزمة المحمولة `Huroof-AlKora-Windows-v1.2.0-x64.zip` مرة واحدة على Windows مع Node 24 و.NET 8 SDK وpnpm 11.19.0، نفّذ:

```powershell
./desktop/scripts/Build-Release.ps1
```

بعدها وزّع الـZIP الناتج واطلب من اللاعبين تشغيل `HuroofAlKora.exe` مباشرة بدون مسؤول ولا نافذة أوامر، شرط توفر WebView2 Runtime.

يمكنك أيضًا رفع هذه الملفات إلى مستودع GitHub خاص ثم تشغيل `.github/workflows/windows-build.yml` لتنزيل حزمة Windows جاهزة من GitHub Actions. **لا تنشر أي مفتاح سرّي أو قاعدة بيانات المستخدمين في المستودع.**

راجع `desktop/README-AR.md` للدليل الكامل والحماية وحدود اللعب الجماعي والمتجر.
